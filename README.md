# HV-Pharmacy

Website tra cứu thông tin thuốc của Khoa Dược – Bệnh viện Đa khoa Hùng Vương.

## Bắt đầu với Claude Code
1. Giải nén thư mục `hv-pharmacy` vào máy (ví dụ `Documents/hv-pharmacy`).
2. Mở Terminal tại thư mục đó và chạy `claude`.
3. Gõ yêu cầu, ví dụ:
   - `Đọc CLAUDE.md rồi cho tôi biết việc tiếp theo`
   - `Điền link Tương tác thuốc: https://script.google.com/.../exec`
   - `Khởi tạo git và hướng dẫn tôi đưa lên Cloudflare Pages`

## Xem thử trên máy
Mở `index.html` bằng trình duyệt (nhấp đúp).

## Sửa nội dung
Tìm khối `CẤU HÌNH` cuối file `index.html`, sửa mảng `TOOLS`, `DOCS`, `VIDEOS`.
